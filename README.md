#  The Quest

## About the Project  
**The Quest** is a 2D side-scrolling platformer set in a medieval world where the player must navigate kingdoms filled with enemies, traps, and collectable coins.  
The main goal is to survive, collect coins, and progress through levels while avoiding dangers.

---

##  Main Goal of the Project  
The purpose of this project is to develop C++ programming skills using **SFML** and **CMake**, and to understand key game development concepts such as:  
- Game loops  
- State management  
- Resource handling  
- User interface and gameplay logic  

---

##  Requirements  
- **C++**  
- **CMake**  
- **SFML**

---

##  Installing  
1. Download the ZIP file of this repository.  
2. Extract the files to your PC.  
3. Open the terminal and enter the following commands:

   ```bash
   mkdir build
   cd build
   cmake ..
   make
   ./the_quest

 ## 🧩 Additional Help
If you encounter this error:

> Failed to load font or texture

Follow these steps:

1. Copy the **absolute path** to your `resources` folder.  
2. Open the file that loads textures (for example, `GameState.cpp`).  
3. Replace the relative path (`resources/...`) with your absolute path.
